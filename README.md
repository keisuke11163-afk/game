# キャッスルフィールド（STEP 1 最小版）

同じ端末で2人が交互に遊ぶ城攻めカードゲーム。兵士と魔法で相手の城HPを0にしたら勝ち。

## 起動方法

```bash
python -m http.server
```

ブラウザで http://localhost:8000 を開く。スマホで遊ぶ場合は、同じWi-Fiにつないで `http://<PCのIPアドレス>:8000` を開く。
（`index.html` を直接ダブルクリックで開くと cards.json を読み込めないので、必ずサーバー経由で開く）

## 遊び方

1. 「プレイヤー1の番です」の画面をタップして開始
2. ターンの始めに自動で **2枚ドロー** → 自分の兵士が **進軍**
3. 手札のカードを **タップで選択、もう一度タップで使用**（1ターンに1枚まで。使わなくてもよい）
4. 「ターン終了」を押すと画面が隠れ、相手に端末を渡す
5. 相手の城HPを0にしたら勝ち

- 手番のプレイヤーが常に画面の下。上が相手の城
- 兵士は自分の城（位置0）から出て、6マスを進み、6マス目を越えたら相手の城を攻撃して消える
  - 出したターンは動かない。歩兵(2マス)は4回目、騎士(3マス)は3回目の進軍で城に着く
- 兵士どうしは戦わない。兵士を倒せるのはサンダーだけ
- 山札がなくなったら、カードの種類からランダムに1枚作って引く（cards.json の count が出やすさになる）
- 手札の上限はない

## ファイル構成

```
index.html         画面の骨組み
style.css          見た目・アニメーション・エフェクト
cards.json         カードの数値・枚数とルールの数値
js/logic/          ゲームロジック（DOMに触らない。後でサーバーへ移せる）
  Game.js          山札・ターン進行・勝敗。起きたことをイベントで返す
  Player.js        城・手札・自分のレーンの兵士
  Castle.js        城のHP（ダメージ・回復）
  Card.js          カード1枚（数値から説明文を作る）
  Soldier.js       場の兵士（HP・攻撃・速度・位置）
js/ui/
  renderer.js      状態の描画とアニメーション
  main.js          起動・タップ操作を Game につなぐ
```

## cards.json の変え方

ファイルを書き換えて保存し、ブラウザを再読み込みするだけで反映される（説明文も数値から自動で変わる）。

```json
{
  "rules": {
    "castleHp": 100,      // 城のHP
    "initialHand": 6,     // 初期手札
    "drawPerTurn": 2,     // 毎ターン引く枚数
    "laneLength": 6       // レーンのマス数
  },
  "cards": [
    { "id": "infantry", "name": "歩兵", "type": "soldier", "count": 10, "hp": 3, "attack": 3, "speed": 2 },
    { "id": "fireball", "name": "ファイアボール", "type": "magic", "count": 6, "effect": "damageEnemyCastle", "value": 8 }
  ]
}
```

※ JSON にはコメントを書けないので、上の `//` は説明用。実際のファイルには書かないこと。

| 項目 | 意味 |
|---|---|
| `count` | 山札に入る枚数（山札切れのときの出やすさにも使う） |
| `hp` / `attack` / `speed` | 兵士のHP・攻撃力・1ターンに進むマス数 |
| `effect` | 魔法の効果。`damageEnemyCastle`（相手の城にダメージ）/ `damageEnemySoldiers`（相手の兵士全員にダメージ）/ `healOwnCastle`（自分の城を回復） |
| `value` | 魔法の効果量 |

- 新しいカードを足すときは、上の `effect` のどれかを使えば JSON に1行足すだけで増やせる（`id` は他と重ならない英字にする）
- 書き間違えると画面下に赤いエラーが出る
